Every icon in the app, current vs. alternative

41 SF Symbols currently in use across LeafID, grouped by where they appear. Two are flagged as worth reconsidering; four more have a plausible alternative if you want to tighten things further.

Apple's SF Symbols font can't be embedded on a web page, so the shapes below are open-source stand-ins (Lucide, ISC-licensed) chosen to match each symbol's silhouette as closely as possible — not Apple's exact artwork. Every current icon shown is confirmed live in the codebase; the real SF Symbol renders natively once you build.
