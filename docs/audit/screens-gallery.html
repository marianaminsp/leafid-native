LeafID — Screens Gallery

Every screen in the LeafID-native codebase — live and dead — reconstructed from the real SwiftUI source: actual copy, actual layout structure, actual Theme.swift tokens. Not a redesign; a baseline of what exists today, before any UI iteration.

Methodology: the iOS Simulator screenshot tool crash-looped irrecoverably (survived a device reboot and a full app restart) — see conversation for detail. Per your decision, these mockups are hand-built directly from each screen's SwiftUI source file, using the exact hex values, spacing scale, and corner radii defined in Theme.swift, and the real copy strings from each view. Layout is structurally faithful (stack order, hierarchy, relative sizing) but not pixel-perfect — text wrapping, exact shadow rendering, and live data (map tiles, captured photos, AI-generated descriptions) will differ from a running device. Where a screen's real behavior depends on data (e.g. an empty vs. populated list), both states are shown side by side.
